# Announcement template

Text to post in your group (replace `@YourBotName`).

```text
📢 UNBAN APPEALS BOT NOW AVAILABLE

From today you can request an unban through our bot: @YourBotName

How it works:
1. Start the bot and follow the on-screen instructions.
2. Your request reaches the admins, who will review it.
3. You will get the answer directly from the bot: if approved, together with the link to rejoin the group; if rejected, with the reason, if any.

Rules:
- Only one open request per user at a time.
- After a rejection, insisting with new requests without a valid reason is not a good idea: admins can block the user from sending further appeals.

Please use it wisely. 🙏
```
